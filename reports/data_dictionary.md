# Data Dictionary: NASA Asteroid Dataset (NeoWs)

Датасет содержит 958 524 близкоземных объекта (астероидов) и 45 признаков.
Источник: NASA/JPL Small-Body Database, Kaggle.

## Идентификация объекта

| Признак | Тип | Описание | Пример |
|---|---|---|---|
| id | строка | Внутренний идентификатор объекта в базе NASA | a0000001 |
| spkid | int | SPK-ID — уникальный числовой идентификатор для расчётов орбит | 2000001 |
| full_name | строка | Полное название объекта | 1 Ceres |
| pdes | строка | Постоянное обозначение (номер или временное обозначение открытия) | 1 |
| name | строка | Собственное имя астероида (если присвоено) | Ceres |
| prefix | строка | Служебный префикс каталога (почти всегда пусто) | — |

## Флаги классификации (целевые признаки)

| Признак | Тип | Описание | Пример |
|---|---|---|---|
| neo | категориальный | NEO — близкоземный объект (пролетает ближе 1,3 а.е. от Солнца): Y/N | Y |
| pha | категориальный | **PHA — потенциально опасный астероид** (большой + близко к Земле): Y/N. Целевая для классификации (ПР5) | N |
| class | категориальный | Тип орбиты по семейству (MBA — главный пояс, APO — аполлоны и др.) | MBA |

## Физические параметры

| Признак | Тип | Описание | Пример |
|---|---|---|---|
| H | float | Абсолютная звёздная величина — яркость объекта (чем меньше, тем крупнее объект) | 3.40 |
| diameter | float | Диаметр астероидов, км. **Целевая для регрессии (ПР4)**. Известна лишь для ~14% объектов | 939.400 |
| albedo | float | Альбедо — доля отражённого света (0..1), светлота поверхности | 0.090 |
| diameter_sigma | float | Погрешность измерения диаметра, км | 0.001 |

## Орбитальные элементы (Keplerian elements)

| Признак | Тип | Описание | Пример |
|---|---|---|---|
| e | float | Эксцентриситет орбиты: 0 — круг, 0..1 — эллипс (чем ближе к 1, тем «вытянутее») | 0.0785 |
| a | float | Большая полуось орбиты — средний размер орбиты, а.е. (1 а.е. = расстояние Земля–Солнце) | 2.767 |
| q | float | Перигелий — минимальное расстояние до Солнца, а.е. | 2.546 |
| ad | float | Афелий — максимальное расстояние до Солнца, а.е. | 2.987 |
| per | float | Период обращения вокруг Солнца, суток | 1682.2 |
| per_y | float | Период обращения, годов | 4.60 |
| n | float | Среднее суточное движение (градусов в сутки) | 0.214 |
| moid | float | **MOID — минимальное расстояние орбиты от орбиты Земли**, а.е. Ключевой признак опасности | 1.59 |
| moid_ld | float | MOID в лунных дистанциях | 619.0 |
| ma | float | Средняя аномалия — положение на орбите на эпоху измерения, град | 145.5 |
| i | float | Наклонение орбиты к плоскости эклиптики, град | 10.6 |
| om | float | Долгота восходящего узла, град | 80.3 |
| w | float | Аргумент перигелия, град | 73.6 |
| tp | float | Время прохождения перигелия | 2459000.5 |

## Оценки точности орбиты (sigma_*)

| Признак | Тип | Описание |
|---|---|---|
| sigma_e, sigma_a, sigma_q, sigma_i, sigma_om, sigma_w, sigma_ma, sigma_ad, sigma_n, sigma_tp, sigma_per | float | Погрешности соответствующих орбитальных элементов (неопределённость измерений NASA) |

## Служебные поля

| Признак | Тип | Описание |
|---|---|---|
| orbit_id | строка | Номер версии орбитального решения |
| epoch | float | Эпоха расчёта орбиты (юлианские дни) |
| epoch_mjd | int | Эпоха в модифицированных юлианских днях |
| epoch_cal | float | Эпоха в календарном формате (YYYYMMDD.0) |
| equinox | строка | Эпоха координатной системы (J2000) |
| rms | float | Среднеквадратичное отклонение остатков наблюдений (качество подгонки орбиты) |
