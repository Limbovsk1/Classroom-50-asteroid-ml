# Предсказание опасных астероидов (NASA NEO)
**Выполнил:** Adylov Arsen

## О проекте
Система оценки потенциальной опасности астероидов на основе реальных
данных NASA (NEO — Near-Earth Objects).

## Обоснование выбора датасета
- **Реальные данные NASA** (JPL Small-Body Database), а не синтетические.
- Одновременно присутствуют две задачи: классификация (pha — опасен/не опасен)
  и регрессия (diameter — диаметр в км).
- Датасет содержит выраженный дисбаланс классов (~0,22% опасных) —
  возможна глубокая работа с метриками и методами балансировки.
- Смешанные типы признаков (числовые, категориальные) и большое число
  пропусков — позволяет отработать полный пайплайн ML.

## Структура репозитория
- `data/raw/` — исходный датасет (не входит в git, см. .gitignore)
- `notebooks/` — практические работы (ПР1 — первичный анализ)
- `reports/` — data dictionary и отчёты
